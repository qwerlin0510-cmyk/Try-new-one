# brand.md：林柔・健康管理教練

## 配色（覆蓋 design-system.md 的 token）

**明亮版**：米白底、深可可字，跟系統預設的深色底相反，所以有兩條規則要改（見下方「明亮版的規則」）。

| Token | 色碼 | 用途 |
|---|---|---|
| `--bg` | `#F7F1E7` | 米白奶油底色（像紙張） |
| `--ink` | `#3E302A` | 主要文字（深可可棕，不用純黑） |
| `--r1` | `#D4907F` | 乾燥玫瑰：要注意的、壞習慣 |
| `--r2` | `#C29A5B` | 暖金：次要強調、手搖飲／甜食 |
| `--r3` | `#E3C29A` | 奶茶杏：**本集主角**、螢光筆重點 |
| `--r4` | `#8FA88A` | 鼠尾草綠：好的做法、蔬菜、中性 |
| `--muted` | `#75665A` | 註腳、出處 |
| `--hi` | `#FFFFFF` | 膠囊標籤底（加淡陰影） |

做 composition 時，把上表的值寫進 `:root`，其餘照 design-system.md。
對比已檢查：`--ink` 在底色上 11.3:1；`--ink` 在每個色塊上都 ≥ 4.6:1；`--muted` 在底色上 4.9:1。

## 明亮版的規則（取代 design-system.md 的對應條文）

- **色塊上的文字用 `--ink`**（不是 `--bg`）：所有色塊都是中淺色，深可可字壓上去才清楚。
- **重點字不換字色**：彩色字在米白底上看不清楚。改成字維持 `--ink`，下面畫一條 `--r3` 奶茶杏「螢光筆」（色塊蓋住字的下半部約 55%～92%）。
- 需要深色底的小卡 → 用 `--hi` 白卡＋淡陰影，不用 `--bg` 85%。

## 畫面偏好：自然、不要 AI 感

- 卡片微微歪一點（−2°～2°），像手貼上去的；圓角大一點。
- 只用很淡的陰影（例：`0 3px 0 rgba(62,48,42,.12)`）；**不用發光、霓虹、漸層、玻璃質感、粒子特效**。
- 動作慢、柔：用 ease-out，不要彈跳過頭。
- 剖面以**血液（血糖）、胃、腸道、肝臟、大腦**為主；食物多用便當、便利商店、手搖飲、早餐店這些上班族日常畫面。
- 「好的做法」用 `--r4` 鼠尾草綠，「要注意的」用 `--r1` 乾燥玫瑰。
- 不畫任何產品包裝、品牌 logo；不畫身材對比、體重計數字。
