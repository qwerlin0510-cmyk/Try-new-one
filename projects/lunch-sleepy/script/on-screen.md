# 畫面建議：午餐吃完為什麼想睡

## 剖面路線
時鐘（大腦裡的生理時鐘）→ 便當（份量）→ 胃 → 血液（血糖曲線）→ 腳（走路）

## 開頭大字（依選定的開頭）
- 1：不吃午餐 也會想睡？
- 2：下午兩點 靈魂出竅？
- 3：想睡 不全是你的錯

## 每段配什麼畫面
| 句子 | 畫面 |
|---|---|
| 下午兩點眼皮打架 | 辦公桌＋時鐘指向 2 點，眼皮慢慢闔上 |
| 原因有兩個 | 兩張卡片：⏰ 生理時鐘／🍱 午餐份量 |
| 生理時鐘、午後低谷 | 大腦剖面＋一條「清醒度」曲線，下午那段往下凹，標「午後低谷」 |
| 不完全是你的錯 | 奶茶杏螢光筆劃「不是你的錯」 |
| 清淡 vs 豐盛午餐 | 左右對照：小份便當 vs 大份便當，右邊人比較恍神（不標熱量數字，或標出處） |
| 換個吃法 | 標題卡「3 招」 |
| 先吃菜和肉，飯最後 | 便當三格依序亮起：🥗 → 🍗 → 🍚，旁邊血糖曲線兩條對照（平緩 vs 尖） |
| 七分飽 | 碗的刻度到七分 |
| 吃完走一走 | 🚶 走路，血糖曲線尖峰被壓平 |
| 我是林柔 | 名字卡 |
| CTA | 「留言 檢測」膠囊標籤 |
